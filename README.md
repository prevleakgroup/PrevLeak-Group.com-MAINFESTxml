# PrevLeak Group™ Ecosystem

Static site and deployment configuration for the PrevLeak Group™ ecosystem.

## Contents

- `index.html` — landing page for the site
- `_config.yml` — Jekyll/GitHub Pages settings
- `.github/workflows/jekyll-gh-pages.yml` — build and deployment workflow
- `firebase.json` and `.firebaserc` — Firebase Hosting configuration
- `oauth.html` — OAuth redirect helper page

## Deployment

- GitHub Pages publishes the site from this repository.
- Firebase Hosting deploys the same static content when the required secret is configured.
